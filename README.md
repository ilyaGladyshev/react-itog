# 📋 React Task Manager (Итоговый проект)

Полноценный менеджер задач с авторизацией, регистрацией и бэкендом на Node.js.  
**Проект учебный**: данные хранятся в JSON-файлах, не предназначен для продакшена.

## Возможности

- Регистрация и авторизация пользователей (пароли хешируются через bcrypt)
- Создание, редактирование, завершение и удаление задач
- Фильтрация задач по статусу и автору
- Экспорт задач в CSV
- Разделение задач по пользователям

## Технологии

**Frontend:**
- React 19
- React Router 7
- Сборка: Vite (или другая — укажи свою, если не Vite)

**Backend:**
- Node.js (чистый `http` модуль)
- JSON-файлы в качестве хранилища (`tasks.json`, `users.json`)
- bcryptjs (хеширование паролей)

> ⚠️ Примечание: хранение данных в JSON-файлах выбрано для простоты и наглядности. Проект не рассчитан на высокую нагрузку или продакшен-среду.

🚀 Как запустить локально
Требования
 (версии 18+)
Клонирование
bash
git clone https://github.com/ilyaGladyshev/react-itog.git
cd react-itog
Установка зависимостей
Фронтенд:

bash
npm install

Запуск 
Бэкенд (в отдельном терминале):

bash
cd backend
node server.js
Сервер будет доступен по адресу: http://localhost:5000

Фронтенд (в другом терминале):

bash
npm start
Приложение будет доступно по адресу: http://localhost:3000

Важно: фронтенд и бэкенд работают на разных портах (3000 и 3001), чтобы не конфликтовать.

API (кратко)
Метод	Путь	Описание
POST	/api/auth/register	Регистрация пользователя
POST	/api/auth/login	Вход, возвращает токен/сессию
GET	/api/tasks	Список задач (с фильтрацией)
POST	/api/tasks	Создать задачу
PUT	/api/tasks/:id	Обновить задачу
DELETE	/api/tasks/:id	Удалить задачу
GET	/api/tasks/export	Экспорт задач в CSV
